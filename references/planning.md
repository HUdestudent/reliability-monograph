# 构思与目录

## 定位本书

从作者材料提炼：研究什么对象，解决什么问题，面向谁，需要哪些数学与工程基础，以及本书相对已有知识提供什么组织方式、方法比较或作者成果。材料不足时给出少量有实质区别的方向及依据，不包装未经核实的创新。

整书规划通常包括一段定位、一条贯穿全书的问题主线、目录及各章任务、资料缺口。若作者已有目录，先评估并尽量沿用；修改时解释重复、断层或先后依赖等具体原因。

目录的粒度服务写作：先给章和节，只有资料支持或用户需要时展开到更深层级。不要为了对称而强制每章同样节数、字数或结构。

## 通用可靠性工程的组织起点

以下是可选的知识模块，不是固定目录；按作者重点合并、删减或调整顺序：

| 模块 | 可承担的任务 | 需要衔接的内容 |
| --- | --- | --- |
| 问题与基本概念 | 确定系统边界、任务剖面、失效判据与度量 | 为后续模型提供对象和定义 |
| 寿命与统计建模 | 说明寿命分布、数据观察方式、参数估计与不确定性 | 将观测数据与模型连接 |
| 系统可靠性 | 从部件扩展到系统结构、依赖与动态行为 | 说明结构假设及其工程意义 |
| 试验与验证 | 论述试验目标、设计、数据处理和模型检验 | 回答如何获得证据、检验预测 |
| 维修与运行 | 研究维修策略、可用性及运行中的更新 | 与前面的失效和系统模型衔接 |
| 方法集成与案例 | 展示从问题定义到分析、验证和决策的完整路径 | 汇总方法选择依据与适用边界 |

不能仅因模块常见就加入没有材料支撑的大章。专著主题较窄时，可以围绕一个核心问题深入展开；概念背景控制在理解后续论证所需的范围。

## 让目录可以直接指导写作

为计划写作的章节建立简短章卡，可合并在目录后：

- 本章回答的问题与读者读完后应理解的结论。
- 已有材料、尚需检索或请作者提供的证据。
- 关键定义、模型与假设，必要的推导、图表或案例。
- 从前文承接什么，为后文留下什么。
- 本章不重复讲解的已定义内容。

整体审视是否出现“后文概念先使用后定义”、多个章节回答同一问题、只列方法不解释选择、案例与前文模型脱节等情况。篇幅建议依据论证密度和作者要求，不默认给出统一章节字数。

## 已有资料驱动的构思

先将材料归为能直接支撑正文、需加工或补证、暂不适配当前主线三类，再调整章节安排。把作者已有论文改为专著内容时，重建章节间关系，统一定义与重复背景，保留成果出处，不把多篇论文直接拼接成书。

有几种合理主线时，给出推荐方案及取舍；作者已经明确方向时直接执行，不再以“选择方案”为必经审批。

## 参考已成书专著结构

当作者提供另一本已成书专著作为参考时，把它当作「结构参考」而非「作者已定目录」，不直接沿用。评估其章节顺序、章间依赖、分章署名与参考文献体系后，按新书定位重组：

- 区分「作者自有目录」与「他人成书目录」：前者尽量沿用，后者是参考素材；作者本人此前出版的书同样按「结构参考」处理，不因作者身份直接沿用。参考成书目录时，若其结构与新书定位（读者、数学门槛、案例导向）冲突，以新书定位为准，不照抄。
- 定位改造有据可依：新书定位与参考成书不同时，据此决定内容的增删与方向。以下是「从理论专著改为应用导论」时的可选做法，不推广到所有定位变化——降低数学门槛（删去不影响结论的公理化证明，指向成书作深化来源）、以案例驱动（每个方法配可操作流程与「何时用/何时不用」边界）、压缩纯综述背景；新书若面向更高水平读者或更理论化，则不降低门槛，反而按新定位补充相应深度的内容。无论何种定位，删减推导不得伤及论证根基，对以数学基础为核心的专著谨慎处理，不能用文字流畅代替模型成立条件。
- 章节顺序的保留或重排给判据：成书章节顺序若本身就是合理的递进（如理论→指标→部件→系统→设计→试验），可保留并说明理由；若新书主线要求不同，明确说明重排依据，不默认照搬。
- 尊重分章作者署名：成书各章的作者署名是既有文献贡献，参考或转述其内容时保留署名信息、不据为己有；与新书作者的贡献区分开。
- 参考文献体系：成书可作为新书整体的参考文献引用；其各章 References 可作为相关章节的文献线索，但需逐条核验题名、作者、标识符后再引用，不直接照搬（见 materials.md）。
- 成书同时是「结构参考」与「资料源」：仅在需引用或转述其内容时，才同时按 materials.md 核验资料与来源；只看目录结构、不转述内容时不强制核验。

已把成书章节归入新书目录时，逐项说明「保留 / 压缩 / 拆分 / 改造」及理由，使参考关系可审查。
