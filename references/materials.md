# 已有资料与文献

## 资料整理

读取用户实际提供的目录、书稿、论文、笔记、数据、图片和模板。使用已有工具提取可编辑文本；遇到扫描件或复杂公式时结合原页核对，不能仅相信 OCR。访问不到的文件记录为未读，不能根据文件名推断其结论。

机翻稿或 OCR 提取常出现符号乱码、断词与公式丢失，按以下方式处理：

- **符号乱码**：原页决定原文写了什么，数学核查判断表达是否成立，两者分别记录。原页可得时忠实转录；若原文有错，保留原文位置和纠错依据，改写稿按任务需要修订。原页不可得时，数学推断只能作为候选；即使按给定定义能唯一推导，也注明“推导恢复、未核原页”，不声称已还原原文。存在多种合理解释时保留原占位及待核验标记，不猜选。上游映射与上下文冲突时记录冲突和核对需求，先继续处理不受影响的内容。
- **断词**（如 `R is k`、下标被拆散）：上下文能明确识别时合并；涉及可能改变变量、下标或含义的歧义时，按符号乱码处理，不自动判作排版问题。
- **公式丢失占位符**（如 `<Formula_3>`、`</Formula_3>`，以及 `<Formura_5>` 这类 OCR 把 `Formula` 误识成 `Formura` 的变体）：标为「待补公式」，可附可核验的旁证提示（如从相邻公式参数反推的疑似形式），但不得臆造公式内容冒充原文；需对照原书原页确认后再填。

为会用于书稿的材料保留简短索引，沿用已有文献管理文件或目录，避免重复造库：

| 项目 | 记录内容 |
| --- | --- |
| 资料标识 | 实际文件、作者给定编号或可追踪来源 |
| 位置 | 页码、节号、图表号、数据表字段或原文段落 |
| 可支持内容 | 具体论断、定义、公式、数据或案例 |
| 对应章节 | 拟使用或已使用的位置 |
| 核验状态 | 已核正文、仅核书目信息、作者提供但未核原始出处、待核验 |

区分原始数据、处理结果与作者解释。重复文件和同一文献不同版本要核对；材料冲突时展示具体冲突及上下文，不能默默拼成一致结论。

## 补充检索

先确定需要支持的具体论断，再检索原始论文、权威专著、官方标准或技术报告。可靠性工程的资料不限于某个期刊系列，不默认限制为 Nature、Science、Cell 等刊物。

核对题名、作者、出版年、来源、标识符与所支撑论断；书目信息匹配不等于全文支持论断。不能用摘要支撑摘要未包含的推导、实验细节或页码引用。只读到摘要时明确其范围。

引用标准时核对发行机构、编号、版本、适用对象及实际可读内容。涉及“现行”“最新”或合规判断时查询官方状态；不能因知道标准名称就推断条款内容。

无法联网或原文受限时可继续写不依赖这些未知内容的部分，在工作稿标记“【待核验：具体论断或来源】”。不要虚构完整参考文献来消除占位，也不要把来源未核实的段落称为定稿。

## 材料进入正文

先说明章节要证明或解释什么，再整合来源；避免逐篇摘要堆砌。不同来源的符号、分布参数化或术语先映射到本书约定，并保留原意及转换依据。

作者提供的结果应注明其材料依据；没有对应证明或数据时，将结论强度调整到证据能够支持的程度。引用、转述和作者贡献须可区分。引文保留准确定位，避免长段拼接来源文字。

引用编号沿用书稿已有制度；大幅重排时使用稳定的文献标识或管理工具，最终再统一编号，避免未完成的引用被误认为正式记录。
