# 可靠性工程技术审校

仅在撰写或审校涉及模型、公式、数据和工程结论的内容时读取。按本章实际内容选择检查项，不要求每章完成全部检查。保留作者已有且自洽的符号体系；发现问题时定位到章节、公式或表格，并解释它会怎样影响结论。

## 审校步骤与记录

1. 提取本节研究对象、事件定义、时间尺度、模型假设、关键公式和结论。
2. 对照用户原始资料、可访问的一手文献或标准正文检查依据；作者叙述、来源结论与本书推导应可区分。
3. 优先检查会改变结论的问题，再处理符号、表达和排版；纠正一处时检查受影响的例题和交叉引用。
4. 对影响结论的计算进行实际复算；记录输入、方法、软件或脚本、输出及容差。未实际运行时只报告解析核查或待复算。

审校结果可用“位置｜问题及影响｜依据与核查状态｜建议改法”记录。按以下边界分级，避免把缺假设一律当错误、把编辑偏好当结论问题：

- **已确认错误**：经解析核查或实际复算证伪，或与同一书稿内既有定义、公式、数据直接矛盾。须给出证据（量纲分析、积分、代入数值、对照原文等）。
- **依赖假设的疑点**：结论本身未证伪，但其成立依赖未交代的假设（如恒定失效率、机理一致性、删失独立性）。标注所需假设，不直接判错。
- **编辑建议**：不改变结论，仅涉及符号、术语、表达或排版一致性的问题。
- **证据不足 / 待复算**：对声称已计算或已验证、但缺少输入与过程的内容，标此状态，补齐输入、方法与结果后再判定；不得当作「疑点」放过，也不得当作「已确认」采信。

依据不足时明确缺少什么，不以推测替换原稿事实。

## 概念、对象与指标

- 术语选择参考 [terminology.md](terminology.md) 的领域与概念说明，并核对作者定义。仅统一措辞且不改变含义时归为「编辑建议」；若译名导致概念、模型或结论发生变化，按实质影响审查，不一律视作文字问题。
- 区分规定任务期间的可靠度与某时刻或区间的可用度，说明任务条件、失效判据、修复是否允许以及统计口径。
- 区分失效概率、概率密度、条件失效率和可修系统的失效发生率；检查量纲、条件事件和时间基准。
- 说明使用日历时间、运行时间、循环次数还是任务次数；不可直接合并不同口径的暴露量。
- 量纲审查先明确量的定义、单位换算和公式。“次/小时”与“小时的倒数”不能仅因是否写出计数标记而判作量纲冲突；单位相同也不意味着失效率、概率密度和失效发生率是同一个量。见 [NIST 关于计数量单位一的说明](https://www.nist.gov/pml/special-publication-330/sp-330-section-2)。
- MTTF、MTBF、MTTR 等缩写首次出现时给出本书采用的定义；涉及均值的关系式需核查适用过程与有限均值等条件。
- 英文来源中的 “repair rate” 可能指失效发生率（ROCOF），不能仅凭字面译为修复完成速率；结合原文定义核对。[NIST 术语说明](https://www.itl.nist.gov/div898/handbook/apr/section1/apr125.htm)

## 寿命分布、参数与公式

- 核对随机变量取值域、初始状态以及连续或离散假设；检查概率范围、密度归一性、边界与极限是否成立。
- 指数、Weibull、对数正态等分布需明确参数含义和单位；注意形状、尺度、率、位置参数及不同软件参数顺序。
- 区分对数寿命的参数与原始寿命的均值、方差；若改变时间单位，检查参数和数值是否同步变换。
- 公式先核查假设、量纲、正负号和特殊情形，再看排版。等价形式可通过推导或数值检验核对，不能只因符号不同判错。
- 恒定失效率、指数寿命或倒数关系不得从单一平均指标直接推定；检查作者是否给出了支持这些化简的模型条件。
- 对正文、符号表、图轴、代码和例题进行一致性检查；来源采用不同符号时建立映射，不静默改变作者的定义。

## 数据、估计与不确定性

- 核对样本单位、失效次数、暴露时间、失效模式、退出原因，以及删失和截断的实际观测机制。
- 区分精确失效时间、右删失、左删失和区间删失；截断涉及样本进入观测的条件，不应仅改标签而沿用删失处理。
- 检查删失样本是否被错误丢弃、当作终止时刻失效或当作永久不失效；定时截尾、定数截尾和多种退出时间须与数据对应。[NIST 删失说明](https://www.itl.nist.gov/div898/handbook/apr/section1/apr131.htm)
- 检查估计量与似然是否对应观测机制；处理竞争失效模式时说明独立性或其他识别假设。
- 区分点估计、置信区间、预测区间与贝叶斯可信区间；注明单侧或双侧、水平、先验及计算方法中实际用到的设置。
- 零失效或少失效结果须保留样本量和暴露量，不直接表述为“不会失效”；模型比较应兼顾诊断、领域依据和估计不确定性。

## 系统模型与维修

- 串并联、故障树和状态模型先说明成功逻辑、任务定义和结构边界；检查所用合成公式的独立性条件。
- 涉及共因失效、载荷共享、备用切换或环境相关性时，核对依赖关系是否进入模型，不能只在文字中提及。
- 区分首次失效寿命与反复失效事件；使用计数过程、更新过程或其他维修模型时核对其时间与状态定义。
- 明确完全修复、最小修复、不完全修复或更换的假设，以及维修时间和停机损失是否计入目标指标。
- 区分瞬态与稳态可用度、运行时间与日历时间；稳态关系式和维修策略比较应交代成立条件与比较基准。

## 试验、加速与外推

- 明确试验目标是估计、验证、筛选、增长还是退化建模；样本分配、停止规则和判据应与目标一致。
- 加速模型需交代失效机理、应力变量、使用条件与试验条件；核查单位、温度尺度及参数的来源。
- 核查加速前后机理一致性、跨应力参数假设及模型选择依据；拟合良好不足以单独支持远距离外推。[NIST 外推说明](https://www.itl.nist.gov/div898/handbook/apr/section4/apr43.htm)
- 将观测范围内结论与使用条件外推区分表述；适用时报告参数敏感性、区间和外推限制。

## 例题、图表与复现

- 先标明数据属于实测、文献摘录、仿真还是教学构造；不把教学数值写成工程实测或验证证据。
- 保留足以复算的参数、单位、数据处理和方法；随机仿真记录种子及关键设置，数值优化记录必要的约束与收敛情况。
- 检查正文、例题答案、表格和图形使用同一输入；合理保留中间精度，解释舍入造成的小差异。
- 图题、坐标、图例与正文结论应对应；展示误差带时说明其统计含义。没有输入数据或实际执行记录，不声称已完成复现。
