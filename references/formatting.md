# 版式与文件交付

## 确定格式依据

按以下顺序确定格式：用户本次要求、出版社或作者提供的模板、书稿已经稳定使用的样式、明确说明的工作格式。拿到模板后检查真实样式、页面与节设置、标题、图表题、公式和参考文献示例，不只凭截图猜测。

没有指定模板时，可使用可调整的工作格式：A4 页面、约 25 mm 页边距、中文正文采用环境可用的宋体类字体、11–12 pt 字号、约 1.5 倍行距；西文与数学字体采用兼容组合。它仅供写作审阅，不代表出版社规范。成书开本、字数和最终排版要求以作者或出版社信息为准。

## 统一规则

- 标题使用语义样式并建立层级和自动目录；尽量不超过正文实际需要的层级。章节重排后更新目录与交叉引用。
- 公式尽可能使用目标格式的可编辑数学表示：Word 使用可编辑公式，LaTeX 使用相应数学环境。确需图片时保留来源或可编辑源文件，不能承诺其可编辑。
- 图、表、式沿用全书编号制度；没有既定制度时可按章编号。区分正文引用与实际编号，检查重复、缺号和指向错误。
- 量符号、单位、上下标和缩写遵守全书约定；排版替换不得改变符号含义、公式分组或参数名称。
- 表格提供必要的表题、单位与注释，避免跨页后失去表头；图题说明必要的条件、数据来源或引用。
- 参考文献使用用户指定的体例及版本；没有要求时先采用一致的工作体例，不能宣称符合某一未核验标准。

## 按需选择输出

只输出用户请求的格式，不默认同时生成多种文件。

| 目标 | 实施重点 |
| --- | --- |
| Word / DOCX | 优先使用环境中可用的文档制作技能或工具，保留样式、目录、题注、公式和交叉引用 |
| LaTeX | 保留可编译源文件、参考文献资源和实际使用的图片；编译后检查缺失引用与布局 |
| Markdown | 保持标题、数学表示、引用标识及图片路径清晰；只有明确要求时才将其作为最终书稿格式 |
| PDF | 从已确认的源文件生成或按要求处理，核对字体、公式、图表和分页 |

缺少转换、数学或渲染工具时说明具体能力限制，交付已经实际生成的可用内容；不得假称文件已生成、可编辑或已完成视觉检查。不要默默把长篇正文压成摘要以迁就格式工具。

## 输出前检查

先检查内容完整性：标题与段落没有遗漏，公式、图表及引用数量和对应关系合理。再使用可用渲染工具检查实际页面，特别留意长公式、宽表格、图题与图片分离、页眉页脚、分页、字体缺字和目录页码。

遵循实际采用的文档工具或技能所要求的渲染验证流程；通常对封面、目录、首章、公式密集页、复杂表格页和参考文献页做重点视觉核对，同时利用批量检查发现其余页的溢出或缺字，再查看异常页。发现问题后修订并复核受影响部分。

最终说明检查覆盖范围和任何待处理项；用户尚未提供出版社模板或只给了部分书稿时，不将工作格式或局部检查称为已满足出版规范。
