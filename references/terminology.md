# 可靠性工程术语的语境化选择

本表是译名选择与概念核查的参考，不是覆盖所有行业的强制标准。先判断领域、定义、研究对象与本书约定，再选择译名；同一概念在同一语境内保持一致。同一英文词可以对应不同概念，不能按词形全书批量替换。

## 系统与对象

| 英文 | 可用译法 | 语境与核查 |
| --- | --- | --- |
| series / parallel system | 串联系统 / 并联系统 | 指可靠性结构时使用；计算机并行架构等其他概念不能仅凭 parallel 改成“并联” |
| standby system | 备用系统 | 区分可靠性备用结构、设备待机状态及具体备用方式 |
| k-out-of-n system | n 中取 k 系统 | 明确 k 对成功部件数还是失效部件数计数，不只统一中文名称 |
| structure / structural system | 结构 / 结构系统 | 区分结构实体、系统连接结构及结构函数，不能把 structure 一律扩译为“结构系统” |
| lifetime / life | 寿命 | 若指生命周期或其他含义，按原概念处理 |
| element / component / unit | 元件 / 部件 / 单元 | 数学集合中的 element 可以是“元素”；工程对象按其层级和作者定义确定 |
| failure | 失效 / 故障 | 根据领域用语、事件或状态的定义确定；不以可修与否作为唯一翻译判据 |
| repair | 修理 / 修复 / 维修 | 明确恢复动作与上位维修活动的关系，按采用的领域术语区分 |
| maintenance | 维修 / 维护 | 不自动扩译为“维修策略”；策略对应 maintenance strategy / policy |
| restoration | 恢复 / 恢复过程 | 核对它指状态恢复、过程还是特定行动，不能仅按中文近义词推断定义 |
| time to failure | 至失效时间 / 失效时间 | 说明时间起点、寿命变量与具体失效时刻的区别 |

## 度量与指标

| 英文 | 可用译法 | 语境与核查 |
| --- | --- | --- |
| reliability | 可靠性 / 可靠度 | 作为属性或能力与作为概率度量时分别处理，不把所有 reliability 改为“可靠度” |
| reliability function | 可靠度函数 | 沿用作者函数定义、符号和任务条件 |
| failure rate / hazard rate | 失效率 / 故障率 / 危险率 | 按领域和定义选择；相同中文词不证明是同一量，区分条件失效率与可修系统失效发生率 |
| availability | 可用性 / 可用度 | 区分属性与定量指标，明确瞬态、区间或稳态定义 |
| MTTF / MTBF / MTTR | 按英文全称和本书定义翻译 | 尤其 MTTR 在不同资料中可能采用不同展开；不能凭缩写推定计时边界或套用倒数关系 |
| risk index / indicator | 风险指数 / 风险指标 | 按原文的数学定义区分，不单靠 index 与 indicator 的字面判断误译 |
| value at risk | 风险价值 / 在险价值（VaR） | 沿用所用来源的译名，并核对分位数方向、损失变量和水平定义 |
| loss function | 损失函数 | 统计损失、经济损失与物理损耗需按定义区分 |

## 统计与特定理论框架

| 英文 | 可用译法 | 语境与核查 |
| --- | --- | --- |
| shape / scale / location parameter | 形状 / 尺度 / 位置参数 | 明确分布参数化、单位与软件约定；不能用术语一致代替参数对应检查 |
| censoring / truncation | 删失 / 截断 | 按观测机制判断，不能只替换名称 |
| estimate / estimator | 估计值或估计 / 估计量 | 区分实现的数值、估计行为和样本的函数 |
| confidence / credible interval | 置信区间 / 可信区间 | 核对频率学派与贝叶斯语境、水平及计算方法 |
| uncertainty | 不确定性 | 不自动认定为某一特定理论框架，也不直接等同模糊性 |
| uncertain measure / chance measure | 不确定测度 / 机会测度 | 仅在来源采用并定义相应不确定理论术语时沿用；不能把一般 random measure 改成 chance measure |
| regular uncertainty distribution | 正则不确定分布 | 先确认来源中的专门定义；这里的译法不推广到所有 regular distribution |

## 工程载荷与应力

| 英文 | 可用译法 | 语境与核查 |
| --- | --- | --- |
| load | 荷载 / 载荷 / 负载 / 负荷 | 结构、电机、机械及运行条件下分别核对含义；例如电机标准使用“负载 load”，不能把“负载”统判为误译 |
| strength / stress | 强度 / 应力 | 根据物理量和失效模型区分 |
| stress level | 应力水平 / 应力等级等 | 区分连续变量取值与离散试验等级，沿用领域和试验方案约定 |

## 使用与来源

- 已有译法自洽时优先保留。与领域定义冲突时先解释具体影响；不能仅因不在本表首选项就判错。
- 只有影响理解、涉及歧义或改变本书约定的决定才另作编辑说明，不为每个常用词增加待办。
