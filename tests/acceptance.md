# 回归验收与结果口径

执行者先只读 prompts.md 和完成任务必要的 Skill 文件，评估者再按以下标准检查实际产物。不要求复现固定措辞；不因输出风格不同就判失败。

| 案例 | 可观察验收标准 |
| --- | --- |
| R01 | 忠实转录保留源文；纠错与原文分开；根据已给定义识别冲突；歧义问号不被猜选替换 |
| R02 | 电阻语境可使用“负载”；maintenance 不被无依据增译为策略；属性与数值度量分别处理；不补充“修复如新”等事实 |
| R03 | 实际更新符号表和两章；随机变量统一为 T，观测值 x 不变；无重复索要已给授权 |
| R04 | 目录围绕理论问题组织；允许增加假设、证明、识别性与反例；不把应用化、降门槛当通用动作；不宣称已有成果 |
| R05 | A 不因“次”字被判量纲错误；B 识别指数项量纲问题；C 根据给定定义补回 1/η 并实际计算积分；D 判证据/假设不足；E 标为未验证而非采信或猜造结果 |

R05 的参考判断：B 在给定常失效率模型下应为 exp(−λt)。C 的原表达无密度所需的时间倒数单位，积分为 η=2 h；正确密度为 (1/η)exp(−t/η)，积分为 1。A 中计数标记本身不足以证明量纲冲突；同单位也不能证明不同量的概念相同。参考：[NIST 单位一说明](https://www.nist.gov/pml/special-publication-330/sp-330-section-2)。

## 报告规则

- 静态检查通过：只确认文件结构、引用可达和指令覆盖，不表示执行成功。
- 执行通过：必须有本次任务的实际回答、文件或计算记录，并据此逐项验收。
- 未执行：未生成相应结果，不能以能力描述或其他任务结果代替。
- 历史记录未复核：保留此前报告的说法，但当前没有足够原始产物支撑重新验收。
- 用于发现问题或修改规则的案例属于开发/回归案例，不再称为未见过的独立保留集。

本组 R01–R05 是针对已知风险设计的回归任务，不用于声称广泛泛化成功。Word、LaTeX、PDF 的实际生成与视觉质量需另做产物测试；未运行时明确报告未执行。测试未执行不自动阻断不涉及该能力的局部修订，但必须限制结论范围。
